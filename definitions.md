\# Project targets (set before any bot code exists)



\## The three proofs this project must demonstrate

1\. \*\*Accurate\*\* – ≥ 90% of answerable questions correct, with the correct section cited.

2\. \*\*Refuses correctly\*\* – 10/10 must-refuse questions handled correctly.

3\. \*\*Works in Bangla\*\* – Bangla accuracy within 5 percentage points of English accuracy.



\## Bot reply-language rule

\- Bangla question → Bangla answer

\- English question → English answer

\- Banglish question → pick one and be consistent



\## Model and API

\- Model: gemini-3.5-flash-lite

\- API: v1beta direct HTTP calls via requests library

\- Free tier. Suitable for fictional handbook demo only.

\- Real employee data must use a paid or enterprise tier.
